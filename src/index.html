              Sign in to use Gmail, Calendar and Drive

              Stay signed in for good (optional, advanced) You don't need this normally: once you've signed in, Friends renews Google's access by itself when it opens and every hour (a sign-in window may flash up for a moment). Set this up only if you still have to sign in again: with an OAuth client of your own, the sign-in is kept in your system keyring and needs no window at all.
              1. Open console.cloud.google.com → Google Auth Platform → Clients and pick your Firebase project at the top.
              2. Create client → Application type Desktop app → name it Friends → Create. Copy the Client ID and Client secret into the boxes below.
              3. Under Audience, press Publish app (otherwise Google ends the sign-in after 7 days). When you sign in, Google says it hasn't verified the app: that's your own app, so choose Advanced → Go to Friends.
              4. Under APIs & Services → Library, make sure Gmail, Google Calendar, Google Drive, YouTube Data API v3 and Google Tasks API are on.
              Friends signs in from ; a Desktop app client allows that by itself.

              1. Open console.firebase.google.com, create a project, and add a Web app (Project settings → Your apps).
              2. Under Authentication → Sign-in method, turn on Google.
              3. Under Authentication → Settings → Authorized domains, add 127.0.0.1 and localhost.
